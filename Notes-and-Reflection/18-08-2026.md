## Notes

### 1. Drawing a Square Using Its Centre and Side Length

We worked on drawing a square when its centre point and side length are known. Instead of directly giving all four corner points, we first calculate the position of each vertex from the centre.

If the centre of the square is `(x, y)` and the side length is `1`, the distance from the centre to each side is `1/2`. Therefore, the four vertices can be calculated by adding or subtracting `1/2` from the `x` and `y` coordinates in different combinations.

For example:

- `P1 = (x - 1/2, y - 1/2)`
- `P2 = (x + 1/2, y - 1/2)`
- `P3 = (x + 1/2, y + 1/2)`
- `P4 = (x - 1/2, y + 1/2)`

After finding the four vertices, the points are joined in order to draw the four sides of the square.

### 2. Rendering a Shape Using Java Swing

We also looked more closely at how a Java Swing program actually draws a shape.

A `JFrame` is used as the main window and a `JPanel` is added to it. When the frame becomes visible, Swing calls `paintComponent(Graphics g)` to draw the contents of the panel.

Inside `paintComponent()`, `super.paintComponent(g)` is called first to clear the previous drawing. After that, the graphics colour and drawing or filling methods can be used to create the required shape.

For example, `setColor()` changes the drawing colour and methods such as `fillRect()` can be used to draw a filled rectangle.

### 3. Java GUI Frameworks

We discussed three Java GUI frameworks: AWT, Swing and JavaFX.

AWT was the earlier Java GUI framework and uses components provided by the operating system. Swing introduced lightweight Java components and gives more control over custom drawing.

JavaFX is a newer framework that supports features such as 2D and 3D graphics, styling and modern user interface development.

### 4. Maven Project Structure

We also looked at the standard structure of a Maven project. The main Java code is placed inside `src/main/java`, while test code goes inside `src/test/java`.

The `pom.xml` file contains the project configuration, including information about dependencies and build settings. Files generated during compilation are stored in the `target` directory.

This standard structure keeps the project organised and makes it easier to build and manage.
