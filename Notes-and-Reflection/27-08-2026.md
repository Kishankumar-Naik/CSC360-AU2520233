### 1. `.class` Files and `.jar` Files

Java source code written in a `.java` file is compiled using `javac` into bytecode stored in `.class` files. A `.class` file generally contains the compiled form of one Java class.

A JAR (Java Archive) file is used to package compiled classes, resources and other files into a single archive. It is useful for distributing or reusing a Java application or library.

The basic process can be shown as:

flowchart LR
    A["Java Source .java"] --> B["javac Compiler"]
    B --> C["Bytecode .class"]
    C --> D["Package"]
    D --> E["JAR File .jar"]
