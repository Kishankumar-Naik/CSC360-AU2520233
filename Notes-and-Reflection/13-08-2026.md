## Notes

### Topic 1: Maven Build System

Apache Maven is a project management and build automation tool mainly used for Java projects. It provides a standard project structure and manages the different stages of building a project.

A Maven project normally contains:

- `src/main/java` for the main Java source code
- `src/test/java` for test code
- `pom.xml` for project configuration
- `target` for files generated during compilation or packaging

Maven follows a standard build lifecycle, which makes Java projects easier to build, test and maintain.

### Topic 2: The `pom.xml` File

The `pom.xml` file stands for Project Object Model. It is the main configuration file of a Maven project.

It contains information such as the project's name and version, Java version, dependencies, plugins and other build settings.

Instead of managing all these settings manually, Maven reads the `pom.xml` file and uses the information to manage the project.

### Topic 3: 2D Transformations

We also discussed basic 2D geometric transformations using Java graphics.

In the `MovingTriangle.java` project, the triangle follows the mouse position using `MouseMotionListener`. `AffineTransform.translate()` is used to move the triangle.

In the `ZoomingTriangle.java` project, a `javax.swing.Timer` is used to continuously change the scale of the triangle. `AffineTransform.scale()` is used for the scaling operation.

The order of transformations is important. For centered zooming, the object is first translated to the required center and then scaled so that the scaling happens around that point.

### Topic 4: Java GUI Frameworks

Java GUI development has evolved through different frameworks such as AWT, Swing and JavaFX.

AWT uses native components, while Swing provides lightweight Java components such as `JFrame` and `JPanel`.

JavaFX is a more modern framework that supports features such as 2D and 3D graphics, FXML and CSS styling.
