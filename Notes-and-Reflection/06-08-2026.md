### 1. GitHub Authentication — SSH vs HTTPS

GitHub repositories can mainly be accessed using two authentication methods: **SSH** and **HTTPS**.

**SSH (Secure Shell)** is used for secure communication and authentication over a network. It uses a **public-private key pair**.

Using `ssh-keygen` generates two keys:
- `.pub` file → Public key
- File without an extension → Private key

The public key can be added to GitHub, while the private key is kept safely on the local computer. After the initial setup, SSH allows Git operations without repeatedly entering credentials.

**HTTPS** uses web-based authentication and can use a username with a Personal Access Token (PAT) or Git Credential Manager. It is easier to start with, while SSH is useful for regular Git development.

### 2. Vector Graphics vs Raster Graphics

There are two common ways of representing digital images: **vector graphics** and **raster graphics**.

**Raster graphics** represent an image as a fixed grid or matrix of pixels. Each pixel stores information such as its colour. Formats such as JPG and PNG are examples of raster images. Raster images are suitable for photographs and detailed images, but their quality can decrease when they are enlarged.

**Vector graphics** represent images using mathematical formulas, shapes and equations. Since the image is calculated rather than stored as fixed pixels, it can be scaled to different sizes without losing its quality.

Vector graphics are commonly useful for things such as logos, SVG images and CAD designs.

### 3. Java 2D Graphics and Transformations

Java 2D graphics use basic geometric shapes such as:
- Points
- Lines
- Rectangles
- Circles
- Polygons
- Curves

In Java AWT and Swing, custom graphics can be created by overriding `paintComponent(Graphics g)` and using the `Graphics2D` object to draw or fill shapes.

Two transformation-based projects were also discussed:

- **MovingTriangle.java** — uses `MouseMotionListener` to track mouse movement and `AffineTransform.translate()` to move a triangle.
- **ZoomingTriangle.java** — uses `javax.swing.Timer` and `AffineTransform.scale()` to continuously change the size of a triangle.

These examples show how geometric transformations can be applied to objects without changing their original shape coordinates.
